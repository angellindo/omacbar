# Triage labels

The skills speak in five canonical triage roles. In this repo they are values of the Notion
`Status` property, not labels.

| Role in mattpocock/skills | Status in our tracker | Meaning |
|---|---|---|
| `needs-triage` | `Needs Triage` | Maintainer needs to evaluate it |
| `needs-info` | `Needs Info` | Waiting on the reporter |
| `ready-for-agent` | `Ready for Planning` (unplanned) or `Ready for Dev` (planned) | Fully specified, an agent can take it |
| `ready-for-human` | `Ready for Human` | Needs a person (hardware, firmware, credentials) |
| `wontfix` | `Won't Do` | Will not be actioned |
